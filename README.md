# dbt-duckdb-pipeline

<img src="./img/dbt_pipeline.png" alt="dbt DuckDB pipeline illustration" width="1200" />

A lightweight starter project for building a local analytics pipeline with dbt and DuckDB, with a Python entry point for orchestration and future automation.

## Overview

This project is intended as a simple foundation for an ELT-style workflow where:

- dbt manages SQL transformations
- DuckDB serves as the local analytical database
- Python can be used to orchestrate jobs, run scripts, or extend the pipeline later
- uv is used for dependency and environment management

The repository is intentionally minimal at this stage and is designed to be expanded as the data model and transformation logic grow.

## Project structure

- `main.py` — starter Python entry point
- `pyproject.toml` — Python project metadata and dependency configuration
- `.python-version` — Python version pin for the project
- `.gitignore` — ignore rules for local artifacts and generated files
- `uv.lock` — lockfile generated by uv

## Prerequisites

Before running the project, make sure you have:

- Python 3.13 or newer
- uv installed on your machine

## Getting started

From the project directory, install dependencies:

```bash
uv sync
```

Run the example entry point:

```bash
uv run python main.py
```

This currently prints a simple startup message and provides a placeholder for expanding the project into a real dbt or data pipeline workflow.

## Recommended next steps

As the project evolves, you can add:

- a `models/` directory for dbt SQL models
- a `profiles.yml` file for dbt connection settings
- seed data or source tables
- Python orchestration logic for running dbt commands
- CI checks and validation for SQL quality and model builds

## Example workflow

A common next step would be:

```bash
uv run dbt debug
uv run dbt deps
uv run dbt run
```

This will help verify the DuckDB connection and build the transformation layer.

## Notes

This project is a starter template, so the current implementation is intentionally simple. It gives you a clean baseline for adding a real dbt + DuckDB pipeline without extra setup overhead.
